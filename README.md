# Лабораторная работа №3 по операционным системам

**Автор:** Казанцев Иван 
**Группа:** ИТ-4  
**Язык программирования:** Python  
**Среда выполнения:** Ubuntu Linux в виртуальной машине UTM на macOS

## Цель работы

Увидеть на практике, как ОС на самом деле выделяет память программе и как устройство памяти влияет на скорость программы.

## Выполненные эксперименты

1. **Выделение памяти** — измерение VmSize, RSS и количества minor page faults при работе с анонимной памятью.
2. **Обход матрицы** — сравнение времени суммирования элементов матрицы по строкам и по столбцам.

## Запуск

```bash
python3 experiment1.py
python3 experiment2.py
```

Результаты измерений сохраняются в папке `Report` в формате CSV.
